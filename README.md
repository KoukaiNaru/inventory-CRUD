# Laravel Gothic TextRPG - Inventory and Economy System

Проект представляет собой ролевую веб-игру в темном готическом стиле с полноценной игровой экономикой, крафтом, добычей ресурсов и управлением инвентарем на базе Laravel и PostgreSQL.

Вся архитектура построена без использования готовых Starter Kits (Breeze/Jetstream), с собственной кастомной авторизацией на сессиях, строгой валидацией прав на уровне моделей и контроллеров, а также покрытием Feature-тестами.

## Игровые механики

- Инвентарь и снаряжение: просмотр, детальные характеристики, продажа и удаление предметов с проверкой принадлежности конкретному пользователю.
- Добыча базовых ресурсов: сбор дерева, камня и железа для последующей ковки.
- Шахта и добыча золота: добыча золота заблокирована без наличия в инвентаре инструмента (кирки). Механика защищена от обхода на уровне бэкенда.
- Кузница и система рецептов:
  - Ковка инструментов и боевого оружия по рецептам с автоматической проверкой и списанием ингредиентов.
  - Индивидуальная ковка оружия с пользовательским названием и описанием.
- Торговая лавка: покупка инструментов и редкого оружия за добытое золото, а также продажа экипировки торговцу.

## Архитектура и база данных

- PostgreSQL в качестве основной СУБД с контролем целостности через внешние ключи и каскадные связи.
- Структура таблиц:
  - users: учетные записи игроков, уровень, баланс золотых монет.
  - catalog_items: глобальный каталог предметов с разделением по типам (weapon, tool, resource), силе урона/эффективности и базовой стоимости.
  - items: экземпляры предметов в инвентаре игроков со связью one-to-many к пользователю и каталогу.
  - recipes: рецепты крафта со связью между целевым предметом и требуемыми ингредиентами.
  - sessions: таблица для нативного хранения сессий Laravel в базе данных.
- Кастомная аутентификация: авторизация через контроллер с сохранением состояния в сессии и защитой маршрутов через middleware auth.

## Интерфейс и анимации

- Кастомный Blade-компонент x-item-icon с векторными SVG-иконками для каждого типа снаряжения (кирки, мечи, кинжалы, топоры, булавы, ресурсы, золото).
- Микроанимации интерфейса (CSS keyframes):
  - rpgPickaxeTap: анимация удара кирки для инструментов добычи.
  - rpgBladeShine: мерцание лезвия и свечение для боевых клинков.
  - rpgGoldPulse: пульсация и световой ореол для золота и монет.
  - rpgFadeInUp и rpgSlideInDown: плавное появление панелей и системных уведомлений.
  - rpgCrestFloat и rpgGemGleam: парение геральдических элементов и пульсация рубиновых разделителей.
  - Тактильный отклик кнопок и карточек с подъемом на 2px и эффектом нажатия scale(0.98).

## Установка и запуск

1. Клонировать репозиторий:
git clone https://github.com/KoukaiNaru/inventory-CRUD.git
cd inventory-CRUD

2. Установить зависимости:
composer install
npm install

3. Настроить окружение:
cp .env.example .env
php artisan key:generate

В файле .env указать параметры подключения к PostgreSQL:
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=inventory_db
DB_USERNAME=postgres
DB_PASSWORD=ваш_пароль

4. Выполнить миграции и наполнить базу данными:
php artisan migrate --seed

5. Собрать фронтенд:
npm run build

6. Запустить локальный сервер:
php artisan serve

Приложение будет доступно по адресу: http://127.0.0.1:8000

## Тестирование
